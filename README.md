🎓 Student Report Management System

📌 Project Description

The Student Report Management System is a web-based application developed to manage and monitor student academic performance. It allows administrators to create student and parent accounts, manage student reports, update marks, track attendance, and view academic progress.

Students and parents can log in to view their academic reports, including subject-wise marks, total marks, percentage, grades, attendance, and teacher remarks.

🚀 Features

- Admin, Student, and Parent Login
- Create and manage student accounts
- Create parent accounts and link them to students
- Add, edit, and delete student reports
- Manage marks for six subjects
- Automatic total marks and percentage calculation
- Automatic grade calculation
- Attendance tracking
- Teacher remarks
- Search student reports
- Performance charts and data visualization
- Download student reports as CSV
- Responsive and user-friendly interface

⚙️ Installation and Setup

Step 1: Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

Step 2: Open the project folder

cd student-report-system

Step 3: Install dependencies

npm install
npm install recharts lucide-react

Step 4: Run the application

npm run dev

Step 5: Open in browser

Open the local URL displayed in your terminal.

🌐 Deployment

This project can be deployed using Vercel.

1. Upload the project to GitHub.
2. Login to Vercel.
3. Import your GitHub repository.
4. Select React / Vite settings.
5. Click Deploy.

🎯 Project Objective

The main objective of this project is to simplify student academic record management, reduce manual work, improve report accessibility, and help students and parents monitor academic progress.
